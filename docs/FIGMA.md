## Screens to design (in order)
1. Landing — hero + live stats header (bills tracked, states, last updated), status ladder, category counts
2. Bills list — filters (state, category, status), bill rows
3. Bill detail — title, plain-English summary slot, status timeline, sponsors, text versions
4. Legislators — cards with photo, party, chamber, district, contact lanes
5. Act Box — address entry, bill selection, letter preview/send states (later phase, design early)

## Working rule
Design in Figma first for look changes; Muse then maps the file's variables/tokens into the web app CSS and verifies against screenshots from the file.
